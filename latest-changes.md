# What changed in agent harnesses: 2026-10-18

Changes to the best-of-Agent-Harnesses list since the 2026-09-13 refresh. The list now ranks 187 agent harnesses, and the star counts below come from GitHub on 2026-10-18.

## New on the list

- **[DeepSeek Harness](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/deepseek-harness/)**, 259k stars, Coding agent products (IDEs, CLIs, full suites): DeepSeek's official open-source agent **harness** (`dsh`), built so that everything is a plugin: the model adapter, tool registry, session log, sandbox and approval policy, and the agent loop itself are Cordis plugins you replace from configuration, and one plugin tree boots as a Web UI, a headless runner, a desktop app, an SDK server, or an ACP server.
- **[Codewhale](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/codewhale/)**, 41.1k stars, Coding agent products (IDEs, CLIs, full suites): Open-source Rust terminal coding agent for any model (40+ providers, local models included).
- **[Grok Build](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/grok-build/)**, 27.5k stars, Coding agent products (IDEs, CLIs, full suites): SpaceXAI's terminal coding agent.
- **[Empryo](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/empryo/)**, 1.4k stars, Coding agent products (IDEs, CLIs, full suites): Coding agent for the desktop, the terminal, and CI.
- **[Tianshu Harness](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/tianshu-harness/)**, 1.2k stars, Coding agent products (IDEs, CLIs, full suites): TypeScript coding-agent runtime shared by a terminal TUI, a desktop app, and a VS Code extension.
- **[Orbi](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/orbi/)**, 225 stars, Coding agent products (IDEs, CLIs, full suites): Self-hosted runner that takes a GitHub issue labeled `ai-ready` to a reviewed, merged pull request and a tagged release: each run gets its own branch and worktree, Pi writes the change, a separate review session checks it against the issue's acceptance criteria, and only the reviewed head merges.
- **[rpi](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/pi-rust/)**, 144 stars, Coding agent products (IDEs, CLIs, full suites): Rust coding-agent runtime that began as a reimplementation of Pi and now develops on its own.
- **[Ouroboros (Q00)](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/ouroboros/)**, 6.3k stars, Coding harness configs and SDKs: Spec-first layer that wraps an existing coding agent (Claude Code, Codex CLI, OpenCode, and ten more runtime families) instead of replacing it.
- **[Ouroboros (razzant)](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/ouroboros-2/)**, 1.6k stars, Personal agent runtimes: Self-modifying personal agent that keeps its identity, durable memory, and history across tasks and restarts.
- **[Open Multi-Agent](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/open-multi-agent/)**, 7k stars, Multi-agent and orchestration: Self-hosted TypeScript multi-agent runtime.
- **[Raven](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/raven/)**, 5.7k stars, Multi-agent and orchestration: EverMind's host agent, with its loop split into memory, planning, capability, and action modules.
- **[HarnessRouter](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/harnessrouter/)**, 3.3k stars, Multi-agent and orchestration: Self-hostable Community Edition of a unified interface for complete agent harnesses.
- **[Agent Teams AI](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/agent-teams-ai/)**, 2.3k stars, Multi-agent and orchestration: Desktop app that runs a team of coding agents (Claude Code, Codex, OpenCode, Cursor, Copilot, and others) on a kanban board: agents take tasks, message each other, and review each other's work before it is accepted.
- **[Orkas](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/orkas/)**, 2.2k stars, Multi-agent and orchestration: Local-first desktop AI team.
- **[Desplega Agent Swarm](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/agent-swarm/)**, 931 stars, Multi-agent and orchestration: Self-hosted multi-agent orchestration service: a lead agent delegates queued tasks to Claude Code, Codex, and other workers in isolated containers.
- **[fractal](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/fractal/)**, 787 stars, Multi-agent and orchestration: Hierarchical coding-agent **harness**: each autonomous loop works in its own git worktree and can delegate separable subtasks to child loops, so the execution tree grows recursively, with five coding-agent CLIs wired into per-node loops, shared SQLite run state, operator controls, and depth, cost, and time limits.
- **[Claudexor](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/claudexor/)**, 518 stars, Multi-agent and orchestration: Local-first control plane that routes one coding thread across Claude Code, Codex, Cursor, and OpenCode.
- **[GraphCode](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/graphcode/)**, 145 stars, Multi-agent and orchestration: macOS canvas that runs Claude Code, Codex CLI, Copilot CLI, and OpenCode sessions as nodes on a graph.
- **[Agent Barn](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/agent-barn/)**, 110 stars, Multi-agent and orchestration: Control plane for teams of agents on your own Kubernetes cluster, deployed with Helm.
- **[deja](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/deja-vu/)**, 1.3k stars, Memory and state: Memory layer built from the session transcripts that Claude Code, Codex, Cursor, and 39 other agents already write to disk, so recall starts with history from before it was installed.
- **[Jev Social](https://ryanalberts.github.io/best-of-Agent-Harnesses/h/jev-social/)**, 176 stars, Research and task-specific harnesses: Local-first social media research agent for Instagram, TikTok, and LinkedIn.
